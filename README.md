# Geyne Lohana — prévia do site (demonstração)

Versão estática do site, publicada pelo GitHub Pages em
https://contatomaxmidiamcz-a11y.github.io/geyne-lohana/

- Gerada a partir do projeto Next.js com `BASE_PATH=/geyne-lohana npm run build`, servidor em :3500 e
  `python3 scripts/export-static.py http://localhost:3500/geyne-lohana <pasta>`.
- Conteúdo de demonstração: empreendimentos ilustrativos; imagens recortadas do PDF de conceito MAXMIDIA (licença a confirmar).
- Formulários, painel /admin e troca de moeda dependem do servidor e não funcionam nesta prévia.
- Páginas marcadas como noindex.
